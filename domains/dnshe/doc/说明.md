## DnsheDomainRenewal
dnshe.comz站点免费域名定时延期脚本 - 每月执行一次

## 关于GitHub版
GitHub版和普通版的区别就是，GitHub版将普通版中的敏感数据放在了环境变量中，运行时先从环境变量中获取并配置数据。\
获取环境变量时会使用EnvManager.swift


**Giuhub**版本环境变量配置:
```
//需要延期域名的API配置信息列表 - 格式：JSON字符串数组
DNSHEDomain_Domains=
```
⚠️注意⚠️：\
如果环境变量需要形如字典，数组等数据时，需要以JSON字符串的方式配置环境变量；\
像普通的：字符串，数字，Bool类型直接配置环境变量皆可，配置Bool值时支持false/true和数字(0解析为false，非0解析为true)。



### DNSHEDomain_Domains配置样式：
```
[
    {
        "User":"用户1 - 只续期Domains中的域名",
        "X-API-Key":"API key",
        "X-API-Secret":"API Secret",
        "Domains":[
            "a.com",
            "b.com",
            "c.com"
        ]
    },
    {
        "User":"用户2 - 当前用户的所有域名都会续期",
        "X-API-Key":"API key",
        "X-API-Secret":"API Secret",
        "Domains":[
        ]
    },
    {
        "User":"用户3 - 当前用户的所有域名都会续期",
        "X-API-Key":"API key",
        "X-API-Secret":"API Secret",
    }
]
```
环境变量DNSHEDomain_Domains配置就是形如这样的JSON数组字段串，其中每一个节点代表一个用户；自动延期用户设置数量不限。
其中参数详解：
- **User**: 用于标记是那个用户需要执行域名续期操作，字段必须存在，但内容不限。
- **X-API-Key**: 域名延期时需要的Key，在dnshe站点的API管理中创建。
- **X-API-Secret**: 域名延期时需要的Secret，在dnshe站点的API管理中创建。
- **Domains**: 当前账户下需要延期的域名(域名全称)，如果设置了则只会延期Domains中配置的域名(必须属于当前用用户)，如果Domains的值为空，或者
Domains字段不存在，那么该账户下的所有域名都会被执行域名续期操作。
