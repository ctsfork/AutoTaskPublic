## 说明
该目录用于存放一些通用的工具模块，其它Swift需要使用这些工具时，只需要将其编译进去即可。


###  Network.swift
对URLSession的进行封装的简单网络请求工具，并且支持Liunx平台。


###  NetworkQueue.swift
使用OperationQueue对Network.swift进一步封装，支持真正的窜行/并发。


### SerialURLSessionRequester.swift
对URLSession简单的封装，并且支持网络依次请求(效果不如NetworkQueue.swift)




### EnvManager.swift
环境变量获取管理工具。 \
获取变量时，同时支持全大/小写和原始输入值: \
\
例如输入：\
名称为Int的环境变量，它会依次取获取名称为：Int,INT,int的环境变量值，并且只要匹配到了一个立即返回。
\
\
**关于复杂结构**：如果需要复杂的数据结构作为环境变量，那么直接将值设置为JSON字符串即可。



### DateTool.swift
对一些常用日期的简单封装。
