## PushBark

## 关于GitHub版
GitHub版和普通版的区别就是，GitHub版将普通版中的敏感数据放在了环境变量中，运行时先从环境变量中获取并配置数据。\
获取环境变量时会使用EnvManager.swift



### PushBark.swift
封装了几个平台的消息通知发送服务，其中包括：
- Bark：https://github.com/Finb/Bark
- Server酱：https://sc3.ft07.com/client
- PushDeer：https://www.pushdeer.com/product.html
- PushGo：支持iOS/Android平台，并且持续更新。但是Android平台通知时效性比较差，除非APP一直保活。


**Giuhub**版本环境变量配置:
```
//Server酱³请求API URL - 其中包括完整的SendKey
//这个URL是由https://sc3.ft07.com/平台生成的。
PushBark_sc3API=


//PushDeer消息发送API URL，其中的pushkey在PushDeer App中获取。
PushBark_pushDeerAPI=


//Bark消息发送API URL - key（在Bark App中获取）放在Body参数中。并且可以推送多个设备。
PushBark_barkAPIs=
//推送设备的key数组
PushBark_barkKeys=



//PushGo消息发送API URL，其中的通道ID和密码(只有在创建时获取)在PushGo App中获取。
PushBark_pushGoAPI=
//PushGo消息发送通道ID
PushBark_pushGoChannelID=
//PushGo消息发送通道密码
PushBark_pushGoPassword=
```
⚠️注意⚠️：\
如果环境变量需要形如字典，数组等数据时，需要以JSON字符串的方式配置环境变量；\
像普通的：字符串，数字，Bool类型直接配置环境变量皆可，配置Bool值时支持false/true和数字(0解析为false，非0解析为true)。
